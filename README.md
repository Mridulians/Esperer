# Esperer Group — Landing Page

A pixel-matched React implementation of the Esperer Group landing page design, built with Vite.

## Stack

- React 19 + Vite
- Plain CSS (`src/App.css`) — no UI framework
- Google Fonts: Playfair Display (headings) + Inter (body/UI)
- All imagery sourced from the provided design and inlined as base64 data URIs (`src/assets/images.js`)

## Structure

Everything lives in `src/App.jsx` / `src/App.css` as a single page: utility bar, nav, hero, about, continuum of care, businesses wheel, global footprint, DINI axis + leadership, insights, CTA and footer.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
